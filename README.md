# Квант: голосовой ассистент для технопарка «Кванториум»

«Квант» — голосовой ассистент для детского технопарка СОИРО «Кванториум». Локальный Python-клиент слушает активационную фразу, распознаёт голосовой запрос и отправляет его в n8n workflow, где работает ИИ-агент с базой знаний KAG. В базу знаний загружена доступная информация с официального сайта Саратовского ДТ «Кванториум»: https://kvantorium64.ru/.

Проект предназначен для запуска на компьютере или Raspberry Pi. Перспектива развития — собрать на Raspberry Pi умную колонку с микрофоном и динамиками, которая будет работать ассистентом в детском технопарке.

## Компоненты проекта

- `main.py` — голосовой клиент: wake word, запись речи через VAD, распознавание речи, отправка запроса в n8n и озвучивание ответа.
- `Quant.onnx` — модель активационной фразы для OpenWakeWord.
- `sound/` — звуки запуска, приветствия и выключения.
- `settings.ini` — настройки webhook, команд, распознавания и VAD-записи.
- `KVANT WITH PY (1).json` — экспорт n8n workflow с ИИ-агентом и подключением к базе знаний KAG.
- Telegram-бот — версия проекта для Telegram, которая умеет принимать текстовые сообщения и голосовые запросы, а затем отправлять их в тот же ИИ-workflow.

## Установка

Требуется Python 3.10+ и рабочие аудиоустройства ввода/вывода.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

На Raspberry Pi или Linux перед установкой Python-зависимостей обычно нужны системные пакеты для PyAudio:

```bash
sudo apt update
sudo apt install python3-dev portaudio19-dev
```

## Настройка

1. Импортируйте `KVANT WITH PY (1).json` в n8n.
2. Проверьте, что workflow активен и webhook доступен.
3. Укажите webhook в `settings.ini`:

```ini
[Settings]
webhook_n8n = https://your-n8n-host/webhook/your-id/chat
```

Webhook можно передать и при запуске:

```bash
python main.py --webhook https://your-n8n-host/webhook/your-id/chat
```

Ключевые настройки речи находятся в секциях `Speech` и `Vad`. `prerollms` сохраняет начало фразы до уверенного определения речи, `minspeechms` отбрасывает слишком короткие звуковые всплески, а `endsilencems` отвечает за паузу, после которой команда считается завершённой. Если ассистент всё ещё рано завершает запись, увеличьте `endsilencems`, например с `900` до `1200`.

## Запуск

```bash
python main.py
```

После запуска ассистент ждёт активационную фразу. После приветствия можно задать вопрос голосом. Для выхода используйте одну из команд из `cmd_exit`, например «стоп» или «выключись».

Во время озвучивания ответа можно нажать `q`, чтобы пропустить речь ассистента.

## Как работает обработка речи

Запрос записывается через VAD: скрипт ждёт реальное начало речи, сохраняет небольшой буфер до начала фразы, а затем завершает запись только после устойчивой тишины. Слишком короткие фрагменты и распознанные одинокие буквы не отправляются в n8n. Это снижает риск обрезания последних слов или слогов перед отправкой текста в n8n.

После распознавания текст отправляется в n8n в формате:

```json
{
  "chatInput": "текст вопроса",
  "sessionId": "uuid-сессии"
}
```

В ответ workflow должен вернуть JSON с полем `output`.

## Перспективы

- собрать автономную умную колонку на Raspberry Pi с микрофоном и динамиками;
- разместить устройство в детском технопарке как голосового справочного ассистента;
- развивать Telegram-бота как удалённый канал доступа к тому же ИИ-агенту;
- расширять базу знаний KAG актуальными материалами технопарка.
